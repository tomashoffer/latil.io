# Logos de Clientes

Colocá los logos de las empresas en formato SVG o PNG en esta carpeta:

- `booking.svg` o `booking.png` - Logo de Booking.com
- `checkpoint.svg` o `checkpoint.png` - Logo de Check Point
- `roku.svg` o `roku.png` - Logo de Roku
- `fiverr.svg` o `fiverr.png` - Logo de Fiverr
- `public.svg` o `public.png` - Logo de Public.com
- `artlist.svg` o `artlist.png` - Logo de Artlist
- `cyera.svg` o `cyera.png` - Logo de Cyera
- `sapiens.svg` o `sapiens.png` - Logo de Sapiens

**Recomendaciones:**
- Formato preferido: SVG (escalable y más liviano)
- Tamaño recomendado: 120px de ancho máximo
- Fondo: transparente
- Color: preferiblemente en escala de grises o con opción de aplicar grayscale

Si no tenés los logos, el componente mostrará el nombre de la empresa como texto.
